# 用户中心头像功能方案 2026-05-07

## 第 1 步：产品经理

### 1. 页面目标
在现有账号中心中补齐头像能力，让用户可以快速识别自己的账号身份，并让头像作为可同步的个人资料字段，跟随账号资产在不同设备间保持一致。

### 2. 用户主任务
1. 查看当前账号头像状态
2. 上传或更换头像
3. 删除头像并恢复默认占位
4. 明确知道头像是否只是本地预览，还是已经成为可同步的持久头像

### 3. 功能清单
- 当前头像展示
- 默认头像占位展示
- 选择图片并上传
- 上传中反馈
- 上传失败反馈
- 删除头像
- 已保存成功提示
- 无图床配置时的限制说明
- 与账号资料资产同步兼容

### 4. 功能优先级

#### P0
- 头像展示
- 上传头像
- 删除头像
- 成功 / 失败 / 上传中状态
- 将头像地址持久化到用户资料资产

#### P1
- 当未开启图床配置时，明确提示头像仅支持可持久化地址，不应误导用户认为临时地址可同步
- 上传按钮禁用态与文案提示

#### P2
- 后续可扩展头像裁剪、拖拽替换、格式/尺寸更细粒度校验

### 5. 信息架构

#### 一级信息
- 账号身份摘要
  - 头像
  - 用户名
  - 邮箱
  - 账号状态辅助信息

- 账号操作
  - 上传 / 更换头像
  - 删除头像
  - 同步账号资产
  - 退出登录

- 资料说明
  - 头像同步说明
  - 图床未配置时的限制说明

#### 数据归属
- 头像 URL 应归属到用户资料资产，而不是项目资产
- 头像变更应走统一的用户资料写入接口
- 头像应随账号资产同步，而不是跟单个项目绑定

### 6. 应进入二级入口的功能
以下能力不应堆在当前账号首页：
- 头像裁剪编辑器
- 历史头像记录
- 多头像版本管理
- 第三方头像源接入
- 项目图片迁移说明

当前首页只保留“展示 / 上传 / 删除 / 状态提示”这组高频主任务。

## 第 2 步：UI 设计师

### 1. 页面区块划分
基于当前账号中心，头像应并入顶部账号摘要卡，而不是新增独立大卡片，避免首页出现多个竞争焦点。

建议区块：
1. 顶部账号摘要卡
   - 左侧：头像
   - 中间：用户名、邮箱、辅助说明
   - 右侧：主要操作按钮（上传/更换）与次级操作（移除）
2. 账号资料列表区
   - 创建时间
   - 最近登录
   - 会话状态
3. 账号同步区
   - 手动同步按钮
   - 同步结果提示
4. 安全操作区
   - 退出登录

### 2. 模块布局建议
- 头像区域与身份信息必须横向成组，形成单一视觉焦点
- “上传/更换头像”是主按钮，“移除头像”是次级文字按钮或轻按钮
- 状态提示放在头像操作区下方，不要插入到资料列表中
- 图床未配置提示使用低强调说明条，不要做成高饱和警告框
- 窄屏下改为纵向堆叠：头像 -> 身份信息 -> 操作按钮 -> 状态说明

### 3. 低保真线框说明

#### 桌面端
[头像 64x64]  [用户名]
              [邮箱]
              [辅助说明：头像将跟随账号资料同步]
              [主按钮：上传/更换头像] [次按钮：移除]
              [状态文案：上传中 / 成功 / 失败 / 未配置图床]

[资料信息卡]
- 邮箱
- 注册时间
- 最近登录
- 会话过期时间

[账号同步卡]
- 同步账号资产按钮
- 同步结果文案

[安全卡]
- 退出登录

#### 移动端
[头像]
[用户名]
[邮箱]
[辅助说明]
[上传/更换头像]
[移除]
[状态文案]

然后再进入资料卡、同步卡、安全卡。

### 4. typography / spacing / colors / radius / icon size 建议

#### Typography
- 页面标题：20-24 / semibold
- 卡片标题：16-18 / semibold
- 头像区用户名：16 / semibold
- 邮箱与说明文案：14 / regular
- 状态辅助文案：12-13 / regular

#### Spacing
- 卡片内边距：24
- 头像与身份信息间距：16
- 用户名与邮箱间距：4-8
- 说明文案与操作按钮间距：12
- 主次按钮间距：8
- 模块之间间距：24

#### Colors
- 默认使用中性色
- 头像占位：深色中性底 + 白色图标
- 成功状态：低饱和绿色文字/浅背景
- 失败状态：低饱和红色文字/浅背景
- 限制说明：琥珀或灰蓝浅提示，不使用高纯度橙红

#### Radius
- 头像：12 或 16
- 卡片：12
- 按钮：8 或 10，与站内现有按钮保持一致

#### Icon size
- 头像占位图标：20-24
- 操作图标若使用：16

### 5. 页面容易混乱或拥挤的风险点

#### 高优先级
1. 头像区不要同时放太多按钮
   - 如果出现“上传 / 更换 / 删除 / 同步 / 编辑资料”全部堆在同一区域，会立刻失去主次
   - 解决：头像区只保留上传/更换与移除，账号同步仍留在独立同步区

2. 状态文案不要与账号基础信息混排
   - 上传结果、未配置图床说明如果混进邮箱/时间列表，会破坏信息层级
   - 解决：状态文案固定放在头像操作区下方

3. 长邮箱与长用户名可能挤压按钮
   - 解决：身份信息区域允许截断或换行，操作区在窄屏下换到下一行

#### 中优先级
4. 默认头像与真实头像风格必须统一
   - 不能真实头像是圆形、占位却是圆角方块且尺寸不同
   - 解决：真实头像和占位使用同尺寸同圆角容器

5. 未配置图床时不能让按钮显得“能永久保存”
   - 解决：按钮可禁用，或允许选择文件但保存前给出明确限制说明

#### 低优先级
6. 成功/失败提示不宜过重
   - 解决：使用轻提示条或小字提示，不要做成抢眼大横幅

## 实施约束
- 头像字段应并入统一用户资料资产，避免额外分叉存储
- 不新增首页级复杂设置
- 保持账号中心只有一个主要视觉重点：身份摘要卡中的头像区
- 必须处理加载态、禁用态、失败态、空状态
