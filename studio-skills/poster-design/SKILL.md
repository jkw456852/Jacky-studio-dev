# 海报设计

## Purpose

把用户的海报需求整理成清晰的视觉方向和执行方案，优先帮助用户完成：

- 活动海报
- 品牌 KV
- 宣传主视觉
- 电商促销海报
- 社媒传播海报

## When to Use

在这些场景优先使用：

- 用户明确说要做海报、KV、主视觉、宣传图、活动视觉
- 用户有品牌、产品或活动诉求，但还没整理成设计执行 brief
- 用户需要先定风格、定版式，再进入出图或素材制作

不优先用于这些场景：

- 纯代码修复
- 纯产品文案润色
- 完整电商详情页长链路制作
- 明确的视频脚本或镜头分镜任务

## Inputs

理想输入包括：

- 品牌名、活动名或产品名
- 海报目标，比如拉新、促销、报名、品牌发布
- 受众画像和投放场景
- 文案、卖点、时间地点、CTA
- 尺寸比例、渠道限制
- 参考视觉或已有素材

如果用户没有一次说全，优先按 `clarify_checklist` 补问。

## Workflow

1. 先判断这是品牌型、活动型、促销型还是社媒传播型海报。
2. 如果信息不完整，先补问目标、受众、文案、尺寸和参考风格。
3. 提炼出 1 到 3 个可执行的视觉方向，不要一上来堆很多方案。
4. 每个方向都要说明：
   - 核心概念
   - 视觉气质
   - 版式结构
   - 主标题与辅助文案关系
   - 推荐图片或元素类型
5. 如果用户要继续出图，再把最优方向整理成清晰的生成 brief。

## Output

默认输出顺序：

1. 任务理解
2. 需要补问的关键缺失项
3. 视觉方向建议
4. 版式和文案结构建议
5. 下一步执行建议

如果用户已经给足信息，可以直接输出：

- 海报执行 brief
- 推荐视觉关键词
- 推荐文案层级
- 推荐出图方式

## Boundaries

- 不要在信息明显缺失时直接假定品牌调性和投放尺寸。
- 不要把详情页模块方案误当成海报方案。
- 不要一次输出过多视觉方向，优先给少量高质量方向。
- 不要只给抽象形容词，必须落到版式、元素、文案结构或画面组织。

## Example Prompts

- 帮我做一个夏季上新活动海报，品牌调性要高级一点。
- 我要给新品精华液做一张主视觉海报，适合小红书投放。
- 给我整理一个商场开业主海报的视觉方向，需要年轻一点。
- 我有产品图和标题文案，帮我定一个促销海报方案。
